---
description: 保存 AI 最后一次回复到 docs 文件夹（save-md [自定义文件名]）
argument-hint: "[自定义文件名]"
---
把 AI 最后一次回复保存为 markdown 文件，放到当前项目根目录（当前工作目录）的 `docs/` 文件夹下。

步骤：
1. 确定要保存的内容：
   - 固定使用当前对话中**最近一条 assistant 回复**的完整内容（不含工具调用记录和系统消息）
   - `/save-md` 后的参数只影响文件名，不影响内容
2. 确定文件名：
   - 若用户传了参数（即本模板参数 `$@` 非空），整个参数作为自定义文件名（可含空格），自动补 `.md` 后缀（已带 `.md` 则不重复加）
   - 否则用时间戳命名，格式：`docs/ai-reply-YYYY-MM-DD-HHmm.md`（如 `ai-reply-2026-08-15-1520.md`）
3. 保存：
   - 确保 `docs/` 文件夹存在，不存在则用 `mkdir -p docs` 创建
   - 用 write 工具把内容写入 `docs/<文件名>`
   - 不要把内容打印到对话里（内容可能很长），写完直接汇报
4. 汇报：用相对路径（如 `docs/ai-reply-2026-08-15-1520.md`）告知保存位置和文件大小，并简要说明保存的是哪一条回复。
