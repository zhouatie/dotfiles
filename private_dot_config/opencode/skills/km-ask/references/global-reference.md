# 全局参考

> 跨域认证、输出格式与通用规则参考。
> 适用于 km-skills 项目中的所有技能。

## 认证

所有 API 调用通过 `popo-cli` 命令执行，认证由 popo-cli 自动处理。

### 认证机制

- 认证由 `popo-cli` 自动处理，无需手动配置
- **无需管理 Token**：不存在本地凭证文件、环境变量或额外 CLI 参数配置

### 注意事项

- 若出现 401/403 错误，确认 popo-cli 登录状态是否正常（尝试重新登录）
- 认证异常时向用户如实报告，不要尝试手动鉴权

## 输出格式

`popo-cli` 返回的数据结构因工具而异，参见各产品域参考文档。

通用规则：
- 成功响应包含 `data` 字段
- 错误响应包含错误码和错误信息
- 分页响应包含 `offset` 和 `hasMore` 字段

## 速率限制

- 默认：每分钟每用户 60 次请求
- 超限时返回 `429 Too Many Requests`
- 批量操作：每次请求最多 100 条

## 时间格式

- 所有时间戳使用 **ISO 8601 UTC**：`2026-01-01T00:00:00Z`
- 仅日期字段使用 `YYYY-MM-DD`：`2026-01-01`

## 资源 ID 格式

- 1-128 个字符
- 仅允许字母、数字、连字符和下划线：`[A-Za-z0-9_-]{1,128}`
- 使用前必须验证格式
- 绝不捏造 ID — 必须从 API 返回结果中提取
