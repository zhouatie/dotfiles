# 字段规则

> 全局字段类型、格式与校验规则，适用于所有 KM API 交互。
> 所有技能在构建 `popo-cli` 请求时必须遵循这些规则。

## 资源标识符

### 资源 ID

- **格式**：`[A-Za-z0-9_-]{1,128}`
- **规则**：
  - 绝不捏造 ID — 必须从 API 返回结果中提取
  - 使用前必须验证格式
  - 区分大小写

### 示例

| 合法 | 非法 | 原因 |
|------|------|------|
| `doc-abc12345` | `doc 123` | 不允许空格 |
| `a1b2c3d4` | `abc` | 过短（最少 1 字符，但实际 ID 通常较长） |
| `my_resource-001` | `doc@#$%` | 不允许特殊字符 |

## 时间戳

### 日期时间字段

- **格式**：ISO 8601 UTC — `YYYY-MM-DDTHH:MM:SSZ`
- **示例**：`2026-03-23T09:00:00Z`
- **时区**：始终使用 UTC（末尾 `Z`），不使用本地时区偏移
- **精度**：秒级（除非 API 明确返回毫秒）

### 仅日期字段

- **格式**：`YYYY-MM-DD`
- **示例**：`2026-03-23`

### 常见时间参数

| 参数 | 格式 | 示例 | 说明 |
|------|------|------|------|
| `created_at` | ISO 8601 | `2026-03-23T09:00:00Z` | 只读，服务端设置 |
| `updated_at` | ISO 8601 | `2026-03-23T12:00:00Z` | 只读，服务端设置 |
| `dateFrom` | YYYY-MM-DD | `2026-03-01` | 筛选：起始日期（含） |
| `dateTo` | YYYY-MM-DD | `2026-03-31` | 筛选：截止日期（含） |

## 分页

### Offset/Size 分页模型

| 参数 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| `offset` | Integer | 0 | 分页偏移量 |
| `size` | Integer | 5 | 每页数量（最大 50） |

### 响应格式

```json
{
  "data": {
    "resourceItems": [...],
    "offset": 5,
    "hasMore": true
  }
}
```

### 规则

- 当 `hasMore` 为 `false` 时停止翻页
- `size` 不得超过 50
- 使用上次响应中的 `offset` 值请求下一页

## 字符串字段

### 标题 / 名称

- **最大长度**：255 字符
- **允许内容**：任意 Unicode 字符
- **处理**：服务端自动去除首尾空白

### 内容 / 正文

- **最大长度**：因资源类型而异（见各产品域文档）
- **格式**：Markdown（默认）或纯文本
- **编码**：UTF-8

### 搜索查询

- **最大长度**：500 字符
- **特殊字符**：由服务端自动转义

## 布尔字段

- API 接受：`true` / `false`（小写 JSON 布尔值）
- 不使用 `"yes"`、`"no"`、`"1"`、`"0"` 等字符串

## 枚举字段

- 始终使用 API 参考文档中记录的精确字符串值
- 跨域常见枚举：

| 字段 | 值 | 描述 |
|------|-----|------|
| `resourceType` | `blog`、`attachment`、`page`、`video`、`topic`、`link` | 资源类型 |
| `sort_order` | `asc`、`desc` | 排序方向 |

## 批量操作字段

### 规则

- **每批最大条数**：100
- **默认批次大小**：50
- 大数据集需拆分为多批次处理

## 空值 / 可选字段

- 可选字段不传即可，不要发送 `null`
- 空字符串 `""` 不等同于 `null`

## 错误响应字段

所有错误响应遵循以下结构：

```json
{
  "code": 400,
  "msg": "错误描述"
}
```

| 字段 | 类型 | 是否必有 | 描述 |
|------|------|----------|------|
| `code` | Integer | 是 | HTTP 状态码 |
| `msg` | String | 是 | 错误描述信息 |
